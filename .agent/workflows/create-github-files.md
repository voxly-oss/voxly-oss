# Create GitHub Community Files

Set up all the community health files needed for an open-source project.

## Steps

1. Create CODE_OF_CONDUCT.md at the project root (Contributor Covenant v2.1)
2. Create SECURITY.md at the project root (vulnerability reporting process)
3. Create CHANGELOG.md at the project root (Keep a Changelog format)
4. Create .github/FUNDING.yml (GitHub Sponsors: ravin972)
5. Create .github/PULL_REQUEST_TEMPLATE.md (PR checklist template)
6. Create .github/ISSUE_TEMPLATE/config.yml (issue template chooser with links to Discord and docs)
7. Create .github/CODEOWNERS (ravin972 as default owner for all files)

Refer to `docs/strategy/github_setup_guide.md` for exact file contents and templates.
