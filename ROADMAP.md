# Voxly Roadmap

> We build in public. This is our honest, live roadmap.

---

## ✅ Now (v2.0 — Released Feb 2026)

- [x] Multi-provider AI (Anthropic Claude, OpenAI GPT-4o, Gemini, Groq, Ollama)
- [x] BYOK (Bring Your Own Key) — per-user API key management
- [x] GitHub webhook integration + AI build failure analysis
- [x] WhatsApp delivery via Twilio
- [x] JWT authentication + multi-agency support
- [x] Docker Compose one-command setup
- [x] `npx create-voxly@latest` CLI scaffold
- [x] Telegram delivery channel
- [x] Vision support (screenshot → GitHub Issue via GPT-4o)

---

## 🔨 Next (v2.1 — March 2026)

- [ ] **Rate limiting** — per-IP brute-force protection on auth endpoints
- [ ] **Slack delivery** — complete integration
- [ ] **pgvector long-term memory** — agents remember past conversations
- [ ] **Multi-tenancy isolation tests** — full test coverage for agency data isolation
- [ ] **CHANGELOG automation** — auto-generated from conventional commits
- [ ] **Privacy Policy + ToS pages** — on voxly.dev

---

## 🔭 Later (v3.0 — Q2 2026)

- [ ] **MCP Server** — expose Voxly tools to Claude Desktop / Cursor
- [ ] **Linear / Jira integration** — sync tasks from project management tools
- [ ] **Figma to GitHub Issue** — design feedback → code ticket automatically
- [ ] **Voxly Cloud** — managed hosted version (SaaS)
- [ ] **Mobile app** — React Native client for agency owners
- [ ] **Analytics dashboard** — usage stats, token costs, delivery rates
